# Compatibility

- Pragman CLI: `>=0.1.0-beta.0 <1.0.0`
- Node.js: `>=22 <25`
- Tested skill hosts: Codex, Claude Code, Cursor portable skill mode

The reasoning and file-drafting workflow remains usable without the CLI. Persisted configuration, schema validation, atomic preview/apply, project linking, audit snapshots, and rollback require a compatible `pragman` executable.
