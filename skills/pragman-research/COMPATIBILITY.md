# Compatibility

- Pragman router/registry: `>=0.1.0 <1.0.0` for provider selection and bounded handoff
- Tested skill hosts: Codex, Claude Code, Cursor portable skill mode

Web, browser, repository, and internal connectors are optional and host-dependent. The native fallback can shape a source plan and analyze user-supplied evidence, but must disclose when it cannot retrieve fresh or private material.
