# Compatibility

- Pragman CLI: `>=0.1.0 <1.0.0`
- Codex session JSONL: format `1`
- Claude Code project JSONL: format `1`
- Cursor exported Markdown: format `1`

Codex and Claude Code provide the complete v1 path. Cursor exported Markdown supports the portable flow. Cursor databases are experimental, version-pinned, read-only, and never required.

Without the CLI, interview the user and analyze only excerpts they deliberately provide. State that deterministic scanning, normalized ingestion, integrity thresholds, change previews, evaluations, and rollback are unavailable.
