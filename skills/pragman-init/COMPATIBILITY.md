# Compatibility

- Pragman CLI: `>=0.1.0 <1.0.0`
- Node.js: `>=22 <25`
- Portable skill workflow: Codex, Claude Code, and Cursor
- Deterministic scan, preview/apply, doctor, and sample-route evidence require a compatible `pragman` CLI.

Host installations remain metadata-only discoveries when their exact version is unavailable. An unsupported or changed version is not assumed healthy.
