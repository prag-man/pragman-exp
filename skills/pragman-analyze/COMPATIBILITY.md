# Compatibility

- Pragman CLI/runtime: `>=0.1.0-beta.0 <1.0.0` for deterministic JSON and Markdown rendering
- Node.js: `>=22 <25`
- Tested skill hosts: Codex, Claude Code, Cursor portable skill mode

Reasoning and a manual Markdown report remain available without the runtime. Event-derived findings require comparable metric definitions and privacy-safe aggregates; raw session discovery belongs to `pragman-unfck`.
